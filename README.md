# Logitech G29 Motherboard Replacement

## Goal

The goal is to create an affordable replacement of the motherboard of the Logitech G29 steering wheel, which currently costs up to 100$.
The estimated cost of the motherboard, if the acquirement of the components is done in batch (without accounting additional labor) should be around 5€ per board.
If not done in batch, the price could be around 30€ (not including tools)
